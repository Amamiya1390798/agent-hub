# Hub 使用说明

**Hub** 就像装在你电脑里的一家小公司，把 **Gemini、Claude、GPT、DeepSeek** 四位 AI 成员组织成一个配合默契的小团队：

- 平时你只需要跟一位**「对接人」**说话——简单的事它直接答；需要几个人配合或听多方意见的事，它替你拉项目组、安排人手，做完把结果交回对话里；
- 面板左侧一组就是一个**「项目组」**，协作时全队共用一块**「项目看板」**同步进度；
- 分工原则是 **Gemini 多干活**，**Claude 和 GPT 主要负责拍板和审查**，**DeepSeek 做零碎小活**。

它直接复用你电脑上各家官方软件已有的登录状态，不用填写或保存密钥；默认以**只读模式**运行，未经你允许不会改动任何文件。

## 安装

需要 macOS、Python 3.9 以上，以及至少一个已登录的 AI 命令行客户端：Antigravity（`agy`）、ChatGPT / Codex（`codex`）、DeepSeek Harness（`dsh`）或 Claude Code（`claude`）。没装的成员会自动换成备用模型。

```bash
git clone <本仓库地址> agent-hub && cd agent-hub
mkdir -p ~/.local/bin          # 确保 ~/.local/bin 在 PATH 里
sh install.sh                  # 先跑离线测试，通过后安装并启动面板
sh app/build.sh                # 可选：编译 macOS 原生窗口 Hub.app（需要 Xcode 命令行工具）
hub ui                         # 打开面板
```

各客户端的可执行文件不在 PATH 里时，可在 `~/.agent-hub/config.json` 的 `bins` 里写明路径。给 AI 助手看的开发说明见 [AGENTS.md](AGENTS.md)。

## 四个角色、分工与备用模型

每位成员都配有「首选 → 备用」自动切换：当前面的模型因额度用完、未登录或超时没能完成时，Hub 会自动换用备用模型顶上，并在结果里标明。

| 角色 | 岗位与日常分工 | 首选模型 | 备用模型 |
| :--- | :--- | :--- | :--- |
| `gemini` | **主力干活**（额度最充裕）：阅读、搜索、整理资料、写初稿、写代码、批量改写等执行类的活默认都给它；还**默认负责拆任务（排工）和最后汇总** | `agy:gemini-4-carbon-high` | `agy:gemini-3.8-flash-high` |
| `claude` | **拍板与把关**（最聪明，额度有限）：定方案、做关键决定、审查重要成果，不做体力活 | `claude:opus` | `agy:gemini-4-carbon-high` |
| `gpt` | **拍板、审查与画图**（综合能力强，额度有限）：定方案、审查代码和结论；另外**只有它能画图**。执行类的活优先给 Gemini | `codex` | `agy:gemini-4-carbon-high` |
| `ds` | **零碎小活**（按量计费、响应快）：适合翻译、格式转换、简短问答、小段代码 | `dsh` | `agy:gemini-3.8-flash-high` |

> 当 Gemini 剩余额度不足（5 小时额度低于 15%）时，排工时才会让其他成员顶上，并在项目看板里写明原因。

## 跟对接人说话（推荐）

- **是什么**：像在公司里找一位项目经理交代事情。你只管跟一位对接人说话——闲聊、小问题它自己直接答；遇到需要拆成几块并行做的大活，或者需要几位独立给意见的事，它会替你派活（发起「自动分工」或「会审」），结果直接回到这段对话里。
- **怎么用**：
  - **在面板里**：打开 Hub **默认就是「对接人」模式**。输入框旁可选**「对接人：自动」**，也可以指定某一位（如 `claude`、`gemini`）。如果对接人替你派了活，对话里会出现一张项目组卡片，**点一下就能进项目组看分工和进度板**。
  - **在命令行里**：
    ```bash
    # 自动选最合适的对接人
    hub chat "我想做一个个人博客，帮我想想从哪里开始、需要准备什么"

    # 指定某一位当对接人
    hub chat --contact gemini "帮我把当前文件夹里的资料整理成提纲"

    # 若对接人把活派给团队，允许队员在指定文件夹里创建或修改文件
    hub chat "按要求改好方案初稿.md" -w ~/Desktop/项目 --write
    ```
- **注意什么**：
  - **「自动」选人的规则**：按当前阶段挑人——聊想法、**定方案找 GPT**；写代码、改文件等**动手的活**，以及总结、翻译、润色等**整理的活找 Gemini**。
  - **额度读不到或低于 15% 的不选**：自动模式只选额度读得到、且 5 小时剩余额度不低于 15% 的成员。因为 **Claude 额度读不到，自动模式不会选它**（想找 Claude 对接，手动选「对接人：claude」或加 `--contact claude` 即可；若所有成员额度都读不到或不足，也会提示你手动指定）。
  - **换人会在对话里说明**：接着聊时，如果阶段变了或前一位额度不够而换人，对话里会清楚写明「现在由谁接手、为什么」。
  - 对接人自己回话时始终只读；开启「允许改文件」（或 `--write`）后，只有它把活派给团队做「自动分工」时，干活的成员才能改文件。

## 发图片

主输入框和旁问小窗都能直接**粘贴图片**（截图后 ⌘V）、把图片**拖进来**，或点「＋图片」选文件（手机上可以直接选照片）。发送前输入框上方会显示缩略图，点 ✕ 去掉；一次最多 6 张，每张不超过 10MB，支持 PNG、JPEG、WebP、GIF。

图片存在 `~/.agent-hub/workspace/attachments/`，交给成员的方式：GPT 直接收到图片；DeepSeek 用它自带的 `read_image` 读图；Gemini、Claude 用各自的工具打开图片文件（Hub 会放行这个文件夹）。记录里会显示你发过的图，点缩略图看大图。画图模式暂时不支持参考图。

## 旁问（开个小窗问个小问题）

主计划在跑、又想顺手查个繁琐的小问题时，点面板右上角「旁问」打开小窗：

- **不进主线**：旁问的记录只在小窗里，不会出现在左边，也不会被主线的追问带上，不打断团队正在做的事。
- **上下文可选**：「基于当前记录」会带上当前打开的那条；「单独问」什么都不带；点某条旁问下面的「接着问」，可以顺着这条旁问继续问。带上文时还能选范围：「完整上下文」带上之前最多 8 轮对话，「只带这一条」只带这一轮的问题和回答。
- **自己选人、模型和思考等级**：先选成员，再选模型和档位（档位名称沿用各模型自己的）；默认跟这位成员平时的设置一样。
- **默认联网**：勾着「需要时上网搜索」时，GPT 打开它自带的实时网页搜索，Claude 放行它自带的网页搜索和读网页，Gemini 用它自带的搜索；DeepSeek 只会被提醒「能搜就搜，搜不到就直说」。回答会尽量附上来源链接。
- 旁问一律只读，不会改文件。

## 追问时续接原会话（省额度、缓存命中更高）

接着上一轮追问时，如果还是**同一位成员、同一个模型**，Hub 会直接续接那位成员上一轮的原生会话（GPT 用 `codex exec resume`，Gemini 用 `agy --conversation`，Claude 用 `claude --resume`，DeepSeek 用 `dsh --session-id`），只发你这一轮说的话，不再把前文整段重发。这样各家的缓存命中更高，也更省额度；对话里会标「续接原会话」。

以下情况不续接，照旧把前文写进提示词、新开一个会话：分叉；从同一条记录第二次追问（等于开了分支，免得两条线混进同一个会话）；换了人或换了模型；上一轮派了团队去做（团队的结果不在原会话里）；旁问选了「只带这一条」。续接失败（比如会话过期）会自动改为带上前文重新问，不用你管。

## 主线分叉

想换个思路试试、又不想打乱原来那条对话时，点记录顶上的「⑂ 从这里分叉」（对接人对话里每一轮回答下面也有）。输入框上方会显示「⑂ 从「…」分叉」，这时发出去的话会**另开一条线**：带上到那一轮为止的上下文，之后两条各走各的。分叉在左边是独立的一组，标着「⑂ 分叉」，点进去顶上有「分叉自 …」可以跳回原来那条。不想分叉了点 ✕ 就恢复成普通追问。

主输入框里不小心点了「接着这条追问」的 ✕，会出现「↩ 改回接着追问」，点一下就恢复。

## 会审

- **是什么**：拿不准主意、想听不同角度意见时，让几位成员**同时、各自独立回答同一个问题**（互相看不到别人的答案），最后再由一位成员（默认 `gemini`）把大家的意见放在一起比较，按「**建议、共同点、分歧与各自理由、还需要确认的信息**」整理给你——不会因为多数人这么说就直接当成事实。
- **怎么用**：
  - **在面板里**：在输入框切到「会审」模式发问题（或点首页「比较几种方案（会审）」模板）。结果页既能看比较结论，也能展开看每一位的原话。
  - **在命令行里**：
    ```bash
    # 用默认成员（gemini、gpt、ds）开会审
    hub council "个人作品集用静态网站还是现成平台更省心？请给建议和理由"

    # 临时指定哪几位参加（逗号分隔）
    hub council "检查这段发布文案有没有歧义或夸大" --agents gemini,ds
    ```
- **注意什么**：
  - **全程只读**：会审只出主意、不改文件（面板切到会审模式会自动隐藏「允许改文件」开关）。
  - **默认成员**：默认由 `gemini`、`gpt`、`ds` 参加；**Claude 默认不参加**，需要时可在面板「⚙ 设置 → 分工方式 → 谁参加会审」里勾选（至少保留两位）。
  - **低于 15% 自动跳过**：5 小时剩余额度低于 15% 的成员会自动跳过，并在它的位置注明原因（额度未知不会误当成 0）。不想跳过的话，在 **⚙ 设置 → 额度快用完的成员** 里选「照样让他干活」，会审、排工、自动对接都会照常安排他。
  - **只剩一位时不综合**：如果跳过或失败后只有一位给出了回答，会直接展示这份回答并注明「没有形成多方会审」，不再多花额度做综合；若多位角色因故障回退到了同一个模型作答，开头也会如实提醒。

## 项目看板（共享进度板）

- **是什么**：每个项目组都有一块全队共用的看板：
  - **自动分工时**：每位成员开工前都能看到**整体目标、全队分工、预计耗时、先后顺序，以及别人的进度和遗留问题**；做完后也会把自己的「进度」和「遗留」写回看板。
  - **会审时**：成员在看板上只能看到问题和谁在参加，**看不到别人的答案**，保证独立思考。
- **怎么用**：不用手动设置，发起自动分工或会审时会自动生成。点开面板里的项目组，在过程区上方就能看到实时更新的「共享进度板」；记录也会同时存成文件 `~/.agent-hub/runs/<编号>/board.md`。
- **注意什么**：如果某位成员有没做完或需要留意的事，看板上会醒目标出「遗留」，方便你和后续接手的成员一眼看到。

## 时限

- **是什么**：每位成员每一步干活最多等多久，**默认 15 分钟**。超时会自动停止这次尝试；如果配有备用模型，会再交给备用模型试试。
- **怎么用**：在面板右上角「⚙ 设置 → 分工方式 → 每一步最多等几分钟」里可改（1～120 分钟，改完即保存）；命令行单次提问 `hub ask` 也可加 `--timeout 秒数`。
- **注意什么**：如果设成**少于 15 分钟，系统会提醒你**——读资料、看代码、审查方案、写长文常常要花 5～15 分钟，时间太短成员很容易写到一半被掐断，什么都交不出来。

## 协作面板（Hub 应用）

双击桌面上的 **Hub**（或在终端运行 `hub ui`）即可打开独立窗口。想一直留在程序坞，右键图标 → 选项 → 在程序坞中保留。关掉窗口后点图标可重新打开，⌘Q 退出窗口；后台服务不会跟着停，想彻底停掉运行 `hub ui --stop`（重新编译安装运行 `sh app/build.sh`）。

- **左边 · 项目组与单独提问**：按**「项目组」**分组——一件事（和对接人的对话、自动分工、会审，或一串连续追问）归在一组，默认折叠，点 `▸` **展开就能看成员、分工和进度**；零碎的单次问答或单张画图归在**「单独提问」**。支持搜索，也可只看「进行中」或「失败」。做完不想再看的，点记录顶上的「归档」（或把鼠标移到项目组卡片、单独提问卡片上，点右边出现的归档小图标（像个收纳盒））就会从列表收起来，**记录不会删除**，点筛选栏的「已归档」能看到并「取消归档」放回去；之后在归档的项目组里接着追问，它会重新出现在列表里。进行中的不能归档。
- **首页模板与草稿自动保留**：新任务页带有一排常用模板，**点一下只填入文字和模式，不会自动发送**（输入框里已有文字时会提醒先清空，不会误覆盖）。打字时**草稿会自动保留**，不小心刷新页面文字和所选模式都不会丢，发送成功后才清空；为安全起见，「允许改文件」刷新后仍默认关闭。
- **中间 · 对话、看板与过程**：跟对接人的聊天、派出的项目组卡片都在这里。点进项目组能看共享进度板、当前同时在做几件、已完成几件（带「接 t1」表示要等 t1 完成，`gemini ×2` 表示分到了两件活）。每一步都能展开看指令、回答、实时输出，做完还能点「复制续聊命令」粘贴到终端里接着聊。
- **底部 · 输入框**：可在「对接人」「自动分工」「会审」、点名某位成员或「画图」之间切换（⌘/Ctrl + Enter 发送）。打开某条记录时默认**接着这条追问**（自动带上文），点 `✕` 则作为新任务。画图由 GPT 生成，直接显示在页面里，保存在 `~/.agent-hub/workspace/images/`。
- **右边 · 团队与设置**：查看忙闲、模型、Gemini 与 GPT 的「5 小时 / 本周」剩余百分比和重置时间（每 5 分钟自动刷新，也可点「刷新额度」；DeepSeek 查余额需在 `~/.agent-hub/.env` 写一行 `DEEPSEEK_API_KEY=…`；Claude 额度请在 Claude 应用里看）。点卡片上的模型名可换下次使用的模型；下面一行「思考等级」可调这位成员想得多深（越深越慢、可能更费额度），档位名称和档数都沿用各模型自己的：Gemini 的档位本来就是不同的模型（如 Carbon Low / Medium / High），所以模型下拉框里同一系列只列一次、档位在这里选；GPT 每个模型档位不同（读 Codex 自带的模型清单，有的有 `ultra`，会自动分派子任务、最费额度）；Claude 是 low / medium / high / xhigh / max；DeepSeek 不支持调节；点「详情」看调用次数（次数不是额度）和备用模型。运行中的任务连点两次「停止」可中止，已结束的可点「重新执行」。
- **⚙ 设置与检查**：点右上角「⚙ 设置」，按「分工方式 / 模型与额度 / 提醒与外观 / 检查与登录 / 用手机控制」分组，改完即保存。「刷新额度」只读数据、不花额度；「检查全部」会给所有已配置模型（含 Claude 和备用模型）发极短消息确认可用，会花一点点额度，平时不用常点。

在终端运行命令或成员中途找队友帮忙的记录，也会同步出现在面板里。面板默认只在本机可访问（打开「用手机控制」后同一 Wi-Fi 下配对过的手机也能打开）；不填工作目录时默认使用 `~/.agent-hub/workspace`。

## 用手机控制

- **是什么**：离开电脑桌时，用手机连上同一个 Wi-Fi 就能打开电脑上的 Hub：看进度、跟对接人说话、下任务、追问或停止任务。
- **怎么用（一步步连接）**：
  1. **电脑上打开开关**：电脑上打开 Hub → 点右上角 **⚙ 设置** → 拉到 **用手机控制** → 点 **「打开手机访问」**（默认关闭，打开后面板会自动重启并显示二维码）。
  2. **手机连同一个 Wi-Fi 扫码**：让手机和电脑连**同一个 Wi-Fi**，打开手机相机扫屏幕上的二维码即可进入（扫不了就在手机浏览器输入二维码下方的地址，再填入配对码）。
  3. **想像 App 一样用**（可选）：
     - **安卓 Chrome**：点右上角 **⋮** → 选 **「添加到主屏幕」**；
     - **iPhone Safari**：点**分享** → 选 **「添加到主屏幕」**。
- **手机上怎么看**：手机屏幕窄，Hub 变成单栏：顶部三个按钮「记录 / 详情 / 团队」来回切换，输入框固定在底部。
- **注意什么（安全说明）**：
  - **只有同一局域网、配对过的手机能进**：外网访问不到；连在同一个 Wi-Fi 下的别人没扫过配对码也进不来（连续输错多次会暂时锁定 10 分钟）。
  - **配对码像钥匙，别外传**：截图发给别人时，注意遮住二维码和配对码。
  - **手机丢了可一键作废**：在电脑设置里点 **「重置配对码」**，之前配对过的所有手机都会立刻失效，必须重新扫码。
  - **设置、登录只能在电脑上改**：分工方式、模型切换、账号登录、手机访问开关都锁在电脑端（手机上只能改浅色/深色外观）。
  - **手机上允许改文件要再确认一次**：在手机上开启「允许改文件」点发送时，会弹窗让你再确认一次，防止小屏幕误触。
  - **不用时可以关掉**：平时不用手机控制时，在电脑设置里点「关闭手机访问」，即恢复成只有这台电脑自己能打开（另外电脑休眠或关机时手机也连不上）。

## 高压模式（DeepSeek 主导）

- **是什么**：下任务时选「高压」方式，由 DeepSeek 负责拆任务和最后汇总。它拆任务之前，会先读一段由你自己写的提示词，再照常把活分给大家。
- **提示词写在哪**：⚙ 设置 → **高压模式提示词**，写完点「保存提示词」。留空就是普通的 DeepSeek 排工。
- **看当时用了什么**：打开那次的项目组，顶部可以展开看到 DeepSeek 当时读到的提示词。
- 命令行：`hub run --pressure "目标"`。

## 其他常用命令

除了面板和 `hub chat` / `hub council`，也可以在终端里直接用这些命令：

### 1. 给总目标，自动拆任务并行完成（`hub run`）
默认由 `gemini` 把目标拆成 1～6 个子任务（简单事只排 1 件，复杂事并行分工，重要成果安排 Claude/GPT 审查），最后由 `gemini` 汇总成完整答复：
```bash
hub run "对比当前目录下三份报价单的优缺点，给出选购建议"
hub run "阅读资料夹全部素材，生成一份周报.md" -w ~/Documents/周报 --write
hub run "策划一场新产品发布会流程" --dry          # 只看拆出的方案，不实际执行
```
> 可选：`--planner` 和 `--synthesizer` 临时换拆任务和汇总的人，`--max-parallel` 限制同时做几件，`--max-tasks` 限制最多拆几件（默认 6）。

### 2. 点名让某位成员干活（`hub ask`）
```bash
hub ask gemini "帮我把当前文件夹里的会议纪要整理成要点"
hub ask claude "审查并直接润色方案初稿.md" -w ~/Desktop/项目 --write
cat 长文章.txt | hub ask ds -                     # 长文件可直接传进去处理（末尾写 -）
```

### 3. 让 GPT 画图（`hub image`）
```bash
hub image "温暖治愈的水彩插画：窗台上的橘猫与咖啡杯" -o cat.png
```
不写 `-o` 时默认保存为当前目录下的 `hub-image.png`。

### 4. 查额度、做体检、看记录
```bash
hub quota               # 查看各成员剩余额度或余额
hub agents              # 体检全部成员的首选与备用模型（会发极短消息，花少量额度）
hub log -n 20           # 查看最近 20 条调用记录
```

## 设置与记录保存在哪

平时所有设置直接在面板右上角「⚙ 设置」里改即可。底层文件和记录都存放在 `~/.agent-hub/` 文件夹下（若设置了环境变量 `HUB_HOME` 则以它为准）：

- **配置文件 `config.json`**（改坏了会自动回退默认设置）：保存四位成员的模型列表、负责拆任务/汇总/兜底干活的默认人选（默认都是 `gemini`）、会审默认成员（`gemini`、`gpt`、`ds`）、最大并行数（默认 `3`）、单步时限（默认 `900` 秒即 15 分钟）以及手机访问开关（默认关闭）。
- **单次调用记录**：`calls.jsonl` 与 `calls/` 文件夹，留存每次调用的时间、耗时与完整问答。
- **归档名单 `archived.json`**：只记下哪些记录被归档了，删掉这个文件等于全部取消归档。
- **项目组存档 `runs/<年月日-时分秒>/`**：每次自动分工或会审新建一个文件夹，留存 `board.md`（项目看板）、`run.json`（运行记录）、`plan.json`（自动分工方案）、`t1.md` / `m1.md`……（每位成员交回的原文）以及 `final.md`（最终汇总答复）。

## 注意事项

- **出错时看得懂**：没完成时会用中文说清「先用哪个模型试了、为什么没成功，又换了哪个」，并给一句建议（比如超时就拆小任务或放宽时限）；英文原始报错收在「技术细节」里，点开才看到。超时前已经写出来的部分回答也会保留，标着「未完成」。

- **允许改文件时是无人值守的**：一旦勾选「允许改文件」（或命令行加 `--write`、运行 `hub image` 保存图片），成员不会再逐条问你，而是直接在工作目录里新建、修改甚至覆盖文件。处理重要资料前请先备份，或指定专门的工作文件夹。
- **成员互相求助最多嵌套 2 层**：某位成员干活时若遇到更适合队友的子问题，会自动找队友帮忙，但最多嵌套 **2 层**，到上限就必须自己完成，不会互相踢皮球；会审等只读任务中求助队友也保持只读。
- **Claude 需先单独登录一次**：首次用 `claude` 前，可在面板设置里点「去登录」（或打开终端运行 `claude` 并输入 `/login`）；若未登录也不会卡住，会自动由备用的 Gemini 顶上。
- **用 `-` 传长文件时不要混写文字**：把文件内容传给命令时，提问位置只能单独写一个 `-`（如 `cat 文件.txt | hub ask gemini -`），不要把提示词和 `-` 混写在一起。
